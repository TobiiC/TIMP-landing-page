# TIMP Tecnologías — Landing page

Página web de **TIMP Tecnologías**: páginas web, automatizaciones y software a medida para pymes y emprendedores.

Sitio estático en HTML y CSS, sin build. Se publica en Vercel: cada push a `main` actualiza la web.

## Estructura

```
index.html        Contenido de la página
style.css         Estilos (colores de marca en :root)
favicon.ico       Ícono de la pestaña
images/           Logos, fotos, íconos y vista previa para redes (og-image.jpg)
```

## Verla en tu compu

Abrí `index.html` en el navegador, o levantá un servidor local:

```bash
npx serve .
```
